# 📖 Lore Elden Ring - đọc theo thứ tự

## Đọc kiểu gì

- **Chưa phá đảo, chỉ muốn hiểu đang xảy ra chuyện gì:** đọc file 1, rồi phần "Bảng tóm tắt nhanh" của file 2. Dừng ở đó.
- **Sắp chọn ending:** đọc file 3.
- **Đã phá đảo game gốc:** đọc hết 1 tới 4, rồi mới sang 5.
- **Chưa chơi DLC:** đừng mở file 5.

## Quy ước trong tài liệu

- Tên riêng (Erdtree, Golden Order, Great Rune...) giữ nguyên tiếng Anh để tra wiki cho dễ
- Chỗ nào game **xác nhận thẳng** thì viết như sự thật
- Chỗ nào là **suy luận từ mô tả item** thì ghi rõ nguồn suy luận
- Chỗ nào là **giả thuyết cộng đồng** thì gọi đúng tên là giả thuyết
